# Bundled fonts

## Architects Daughter

- **Designer:** Kimberly Geswein
- **Licence:** SIL Open Font License 1.1 — https://scripts.sil.org/OFL
- **Source:** https://fonts.google.com/specimen/Architects+Daughter

Bundled rather than loaded from a font CDN: PearBoard is peer-to-peer and
should not need a network request to render a board correctly.

Used as the hand-drawn font. Excalidraw's own Excalifont is not open for
redistribution, so this stands in for it — hand-printed rather than cursive,
which is the closer match.
